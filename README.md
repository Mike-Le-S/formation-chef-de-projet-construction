# Formation Chef de projet construction (Suisse romande)

Formation complète pour passer du terrain (contremaître, chef d'équipe) à la direction de projet dans la construction, avec le contexte suisse romand : normes SIA, CFC/CRB, marchés publics LMP/AIMP, gestion financière de chantier.

## Télécharger tout d'un coup

Bouton vert **« Code » → « Download ZIP »** en haut de cette page, ou lien direct dans les [Releases](../../releases).

## Contenu

**`modules/`** : les 7 fascicules PDF, à lire dans l'ordre.
1. Module 0 : Guide du parcours (commencer par lui)
2. Module 1 : Les acteurs du projet
3. Module 2 : Phases SIA et CFC
4. Module 3 : Contrats, normes, marchés publics
5. Module 4 : Planification et pilotage (chemin critique)
6. Module 5 : Gestion financière SMIT
7. Module 6 : Leadership et management

**`corriges/`** : les corrigés détaillés des exercices (un fascicule par module). Faire les exercices avant de les ouvrir.

**`outils/`** :
- `SMIT-gestion-financiere.xlsx` : outil complet de gestion financière de chantier (budget par CFC, ventilation Salaires/Matériaux/Inventaire/Tiers, engagé, facturé, prévision fin de chantier, cash-flow, tableau de bord avec alertes), pré-rempli avec un chantier fictif d'exemple. Nécessite Excel 2019+ ou LibreOffice.
- `matrice-risques.xlsx` : registre et matrice de risques 5×5.
- `modele-pv-seance.docx` : modèle de procès-verbal de séance de chantier.
- `checklist-reception-SIA118.docx` : checklist de réception d'ouvrage.

## Avertissement

Support de formation privé, sans valeur contractuelle ni juridique. Les contenus issus de normes payantes (SIA, CRB) et les seuils ou taux cités sont restitués de mémoire et signalés comme tels dans les documents : toujours vérifier les textes officiels en vigueur (norme, loi, contrat) avant toute décision professionnelle.
